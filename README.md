# Newsapp
Edmonton News Map — Android Prototype

This is a deliberately small proof-of-concept for a location-based Edmonton news app.


What works


Android app shell

Edmonton-style map canvas

Five sample news events

Approximate location bubbles

Tap-to-open story details

Map/List toggle

Clear indication that locations are approximate


What is intentionally not included yet


Live news feeds

Automatic article ingestion

Geocoding

Real map tiles

User accounts

Push notifications

Production database


Run

Open the project in Android Studio and let Gradle sync. Then run the app configuration on an Android emulator or connected device.


The sample locations are illustrative, not real event coordinates.
